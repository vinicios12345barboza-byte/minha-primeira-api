# 🎮 API REST - Gerenciamento de Jogos

API RESTful simples desenvolvida para prática de conceitos fundamentais de backend, manipulação de rotas HTTP, tratamento de erros e tipagem estrita com TypeScript.

## 🚀 Tecnologias Utilizadas

- **Node.js** (com suporte a módulos ES/ESM)
- **TypeScript**
- **Express**
- **REST Client** (para testes de endpoints no VS Code)

## 📌 Funcionalidades (CRUD)

- `GET /jogos` — Lista todos os jogos cadastrados.
- `GET /jogos/:id` — Busca os detalhes de um jogo pelo ID.
- `POST /jogos` — Cadastra um novo jogo.
- `PUT /jogos/:id` — Atualiza as informações de um jogo existente.
- `DELETE /jogos/:id` — Remove um jogo da lista.
